This starter Log exists to prove the v1 technical foundation end to end.

<Callout variant="decision">
  Astro + MDX keeps Workshop Terminal static-first while still allowing richer writing components when a Log needs them.
</Callout>

The setup in this repository now covers:

- typed content collections for Logs, Projects, and Routes
- static route generation for collection entries
- RSS output for published Logs
- a GitHub Pages deployment workflow

That gives future content, information architecture, and visual design work a clean base without adding a backend or client-side app shell.
